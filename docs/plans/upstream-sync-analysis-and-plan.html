3. Detailed Conflict Hotspot Inventory

Hotspot A: Effect rc.112 Tagged Error Syntax Migration

In packages/contracts/src/provider.ts and settings.ts, Effect rc.112 replaced Schema.TaggedErrorClass with Schema.TaggedError: 

// Deprecated in Effect rc.112:
export class ProviderEphemeralQueryError extends Schema.TaggedErrorClass<ProviderEphemeralQueryError>()(...)

// Required in Effect rc.112:
export class ProviderEphemeralQueryError extends Schema.TaggedError<ProviderEphemeralQueryError>()(...)

Any local error class must be updated to Schema.TaggedError during the merge to pass compilation.

Hotspot B: Antigravity Skills and Driver Integration

Upstream created resolveAntigravityUserHome(platform, processEnv) in AntigravitySkills.ts to locate ~/.gemini skills. Local had implemented inline home resolution and added fast executable resolve probing, cached models, and live quota queries.

Resolution Strategy

Adopt upstream's formal resolveAntigravityUserHome helper while preserving all local enhancements (cached models JSON read/write, live quota streaming, and fast non-spawning probe).

Hotspot C: ChatComposer & Resting Behavior

Upstream eliminated composerCollapseOnBlur in favor of scroll-only resting (composerCollapseOnScroll) and added SnapShot attachment frames and question attachment staging. Local added the isBtwCommand check to allow sending ephemeral questions while a thread is running.

Resolution Strategy

Accept upstream's improved resting composer layout and SnapShot frames. Re-inject local's parseBtwCommand(prompt) handling and connecting phase indicators.
